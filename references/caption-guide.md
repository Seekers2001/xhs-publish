## 1. 标题写作公式（5 种模板）

### 1.1 数字+结论型（干货类最常用）
```
格式：「数字」+ 结论/方法/清单
示例：
- 5 个让你效率翻倍的工作方法，第 3 个最实用
- 入行 3 年总结的 8 条审计经验，新人必看
- 10 分钟搞定的 Excel 技巧，同事都来问我怎么做的
```

### 1.2 问题+答案型
```
格式：疑问句 + 隐含答案
示例：
- 为什么你的报告总被打回？可能忽略了这 3 点
- 审计底稿怎么写才不返工？老会计的方法太好用了
- Excel 公式总出错？一定是没注意这个细节
```

### 1.3 场景+方法型
```
格式：痛点场景 + 解决方案
示例：
- 加班到凌晨还在做底稿？试试这套自动化模板
- 第一次做审计不知道从哪入手？按这 5 步走就对了
- 领导突然要数据但 Excel 巨乱？3 步快速整理
```

### 1.4 对比反差型（种草类常用）
```
格式：之前 vs 之后 / 不知道 vs 知道后
示例：
- 用了这个方法后，我的底稿再也没被退回过
- 以前 1 天做的报表，现在 10 分钟搞定
- 后悔没早知道的审计工具，效率提升 300%
```

### 1.5 悬念+情绪型（故事类常用）
```
格式：引发好奇 + 情绪共鸣
示例：
- 做审计第 5 年，我终于想通了一件事
- 那次审计翻车经历，差点让我转行
- 同事偷偷用的 Excel 插件，我不说你根本不知道
```

## 2. 正文结构模板

### 2.1 干货型正文结构
```
第 1 段：一句话点明主题（这篇分享 XX，适合 XX 人群）
第 2 段：分点列出核心内容（用 emoji 分隔，3-5 个要点）
第 3 段：总结+引导（收藏不迷路/关注看更多）
第 4 段：系列引导 + 话题标签
```

### 2.2 种草型正文结构
```
第 1 段：痛点共鸣（你是不是也 XX？/ 每次 XX 的时候...）
第 2 段：解决方案介绍（后来我发现了 XX）
第 3 段：使用效果（具体数字/对比/截图说明）
第 4 段：推荐理由 + 引导互动
第 5 段：话题标签
```

### 2.3 故事型正文结构
```
第 1 段：背景引入（时间/地点/起因）
第 2 段：过程描述（遇到了什么/怎么做的）
第 3 段：转折或高潮（关键发现/顿悟时刻）
第 4 段：收获总结（学到了什么/建议什么）
第 5 段：互动引导 + 话题标签
```

## 3. SEO 关键词布局技巧

### 3.1 关键词放置位置（按优先级）
1. **标题**：核心关键词必须出现在标题中
2. **正文第一句**：重复或同义词出现
3. **话题标签**：精准匹配用户搜索词
4. **正文中间**：自然融入 2-3 次

### 3.2 关键词选择策略
```
核心词（1-2 个）：流量大，竞争激烈
  例：审计、Excel 技巧、工作效率

长尾词（3-5 个）：精准匹配，转化率高
  例：审计底稿模板、Excel 自动化报表、新人审计入门

场景词（2-3 个）：描述使用场景
  例：加班必备、职场新人、年底盘点
```

### 3.3 避免踩坑
- 不要堆砌关键词，影响阅读体验
- 不要用完全不相关的热门标签蹭流量
- 标题中关键词放在前半部分（系统截断显示时能看到）

## 4. 话题标签选择策略

### 4.1 标签组合公式
```
5-8 个标签 = 2 热门 + 3 精准 + 2 长尾 + 1 场景

热门标签（10w+ 浏览）：#职场干货 #高效办公 #学习笔记
精准标签（1w-10w）：#审计入门 #Excel技巧 #工作方法论
长尾标签（<1w）：#审计底稿模板 #Excel自动化 #审计新人必看
场景标签：#加班人的救星 #打工人效率工具
```

### 4.2 查找热门标签的方法
1. 小红书搜索框输入关键词，查看下拉推荐
2. 查看同类高赞笔记使用的标签
3. 使用小红书「话题」页面查看热度

### 4.3 标签格式
- 用 `#标签名` 格式（中间无空格）
- 标签之间用空格分隔
- 放在正文末尾，不要穿插在正文中

## 5. 不同内容类型的文案示例

### 5.1 教程类
```
标题：Excel 自动合并报表，5 分钟搞定 100 个文件（附模板）
正文：
每次月末要合并几十个分公司的报表，手动复制粘贴到崩溃...

今天分享一个超好用的方法，用 Python 自动合并：
1. 把所有 Excel 放在同一个文件夹
2. 运行脚本，一键合并
3. 自动生成汇总表

实测 100 个文件只要 5 分钟，之前要做一整天

模板和代码放在评论区，需要的自取

#Excel技巧 #办公自动化 #Python办公 #职场效率 #报表合并
```

## 6. 发布时间建议

| 时段 | 适合内容 | 原因 |
|------|---------|------|
| 7:00-9:00 | 干货/教程 | 通勤时间，碎片化学习 |
| 12:00-13:30 | 轻松/种草 | 午休浏览 |
| 18:00-20:00 | 故事/经验 | 下班放松，愿意读长内容 |
| 21:00-23:00 | 所有类型 | 晚间黄金时段，流量最高 |

**最佳发布日**：周二至周四流量相对稳定，周末竞争激烈但总量也大。

## 7. 互动引导话术

### 7.1 评论引导
```
- 你觉得最有用的是哪一点？评论区告诉我
- 还有什么想了解的？评论区留言，下期安排
- 踩过同样的坑吗？分享你的经历
```

### 7.2 收藏引导
```
- 建议先收藏，用到的时候方便找
- 码住！以后一定用得上
```

### 7.3 关注引导
```
- 关注我，持续分享 XX 干货
- 系列内容更新中，关注不迷路
```

### 7.4 系列引导（多条笔记时）
```
- 这是系列第 X 篇，共 N 篇，合集在主页
- 上一篇/下一篇链接在评论区置顶
- 从第 1 篇看效果更好，主页找合集
```

## 8. 写作注意事项

1. **口语化**：小红书用户偏好自然、亲切的表达，避免过于正式
2. **分段短**：每段 2-3 句话，方便手机阅读
3. **善用 emoji**：适当使用 emoji 分隔要点，但不要过度
4. **真实感**：分享真实经验和数据，比空泛建议更有说服力
5. **互动感**：末尾留一个问题或引导，提升评论率
6. **系列化**：多条笔记时，明确标注系列信息，方便用户追更
